# Informasi Dataset

## Nama Dataset
SMS Spam Collection

## Sumber
UCI Machine Learning Repository

## Tujuan
Dataset digunakan untuk demonstrasi Machine Learning dalam klasifikasi spam dan ham.

## Struktur CSV

Dataset dikonversi menjadi `spam.csv` dengan dua kolom:

| Kolom | Keterangan |
|---|---|
| label | Kelas pesan: ham atau spam |
| message | Isi teks pesan |

## Privasi

Repository tidak menyimpan email pribadi, data mahasiswa, password,
API key, token, atau data sensitif lainnya.
