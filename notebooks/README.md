# Folder Notebook

Folder ini berisi notebook Google Colab untuk proyek deteksi spam email.

File utama:

- spam_detection_colab.ipynb

Notebook melakukan:
- pembacaan dataset CSV;
- pembersihan data;
- pembagian data latih dan data uji;
- ekstraksi fitur TF-IDF;
- pelatihan Multinomial Naive Bayes;
- evaluasi classification report dan confusion matrix;
- prediksi pesan baru.
